## 🚀 Como Usar no OmniArc

1. Abra o aplicativo:
   ```bash
   cd /home/hokyozu/Documentos/Dev/omniarc && ./run.sh
   ```
2. No topo direito, clique em **Carregar Projeto**.
3. Selecione o arquivo [`presets/jujutsu_kaisen.omniarc.json`](file:///home/hokyozu/Documentos/Dev/omniarc/presets/jujutsu_kaisen.omniarc.json).
4. Todos os **10 blocos** serão carregados instantaneamente com seus respectivos episódios, durações estimadas e legendas PT-BR sincronizadas!
